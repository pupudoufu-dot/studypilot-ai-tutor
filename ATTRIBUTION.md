# Attribution

StudyPilot is an independent, from-scratch implementation focused on
misconception diagnosis, progressive hints, confidence-based routing, and
reproducible product evaluation.

The project direction was informed by the open-source repository
[`bcefghj/multi-agent-education`](https://github.com/bcefghj/multi-agent-education),
which is published under the MIT License. StudyPilot does not copy that
repository's Java/Go implementations, five-agent mesh architecture, interview
guide, or unverified performance claims. Its Python workflow, benchmark,
documentation, tests, and web prototype were created separately for this
project.

AI-assisted coding was used during implementation. Product definition,
workflow decisions, evaluation dimensions, evidence boundaries, and final QA
were directed by Bingyan Liu.
